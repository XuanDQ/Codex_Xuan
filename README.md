## 如何下载到自己的电脑或手机

- 下载全部资料：在 GitHub 仓库页面选择 **Code → Download ZIP**，下载后在本机解压。
- 下载单个文件：打开对应文件页，选择 **Download raw file / 下载原始文件**；按钮名称可能因界面语言不同而变化。
- 各课目录中的 `语音包` 含6段章节语音，另有完整纯人声MP3、SRT字幕、逐场景讲稿、可编辑PPT、教师手册及Arduino基础示例。

## 规范与制作说明

采用制作规范v1.1；第二课已同步修正USB、ESP、BT等缩写的配音读法。所有文件从已验证的v1.1课程包迁入，原始云端文件保留。完整压缩包超过GitHub单文件限制，因此在仓库中按两课解包存放。文件校验值见 `文件清单_SHA256.json`。

两课的视频整片解码、字幕时间顺序、PPT备注和压缩包完整性已检查。实际ESP32硬件连通、Arduino板包编译和Android实机安装仍需教师课前在机构设备上验证。

源码用于保留制作过程，依赖原制作环境、模型、字体与课件截图，不是跨平台一键安装包。语音模型许可及素材来源见各课目录；原用户课件素材的权利不因本次迁移而改变。
